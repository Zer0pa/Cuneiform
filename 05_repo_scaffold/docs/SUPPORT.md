# Support

## Routing

| Need | Route |
|---|---|
| Reproducible bug | GitHub bug report |
| Evidence or claim dispute | GitHub evidence dispute |
| Feature request | GitHub feature request |
| General question | GitHub question template |
| Security issue | Private route in `../SECURITY.md` |

## What To Include

- repo version, branch, or commit
- operating context
- exact artifact or file path involved
- expected behavior versus observed behavior
- any owner-held dependency or limitation already known

## Response Expectations

| Request Type | Expected Handling |
|---|---|
| Bug | Best-effort internal triage once the report names the exact file or artifact path |
| Question | Clarify the current staged truth without upgrading the lane posture |
| Evidence dispute | Compare the disputed claim against the staged evidence and downgrade the claim if needed |
| Feature request | Review against the control-pack mission; generic methods requests may be redirected elsewhere |

## Boundary Note

Support replies do not change repo truth by themselves. Public claims change
only when the evidence and docs surface are updated.
