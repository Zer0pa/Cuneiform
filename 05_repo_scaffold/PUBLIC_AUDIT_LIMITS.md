# Public Audit Limits

## Purpose

This staged control pack can establish only what the visible artifact and
documentation surface support. It must not be read as proof of a repaired
cuneiform result or a public-ready standalone repo.

## What A Public Audit Can Establish

| Surface | What It Can Show |
|---|---|
| Source tree | The lane is intentionally framed as benchmark/control only and bounded by explicit source and data policies |
| Published artifacts | The inherited P5 gate failed and the pack preserves that failure instead of narrating around it |
| Tagged or pinned snapshot | A dated migration-stage view of the control pack and its current blockers |
| Docs coherence | Whether the public truth surface is internally consistent |

## What A Public Audit Cannot Establish

| Missing Input | Why It Matters |
|---|---|
| Full upstream cuneiform corpora and image-bearing assets | Some sources remain fetch-only or rights-constrained, so a public clone cannot rerun the whole lane as-is |
| A clean extracted code package | This scaffold does not yet contain the extracted installable rerun code surface |
| Future gate-repair evidence | No document here proves that the failed governing metric has been repaired |

## Rules For Interpreting This Repo

- Do not infer private results from public prose.
- Do not turn roadmap intent into proof.
- Do not use portfolio-level language unless this repo evidences it directly.
- Treat `UNKNOWN`, `UNVERIFIED`, `INFERRED`, and `OWNER_DEFERRED` as real
  states, not as placeholders to gloss over.

## Disputes

If a public statement appears to outrun the evidence surface, open an evidence
dispute and cite the exact file, line, and missing artifact path.
